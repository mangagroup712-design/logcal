# LOGCAL
タスク管理とカレンダーを融合させた、使いやすくて高機能なウェブアプリです。

# つかいかた
画面下部の3つのタブ「ホーム」「カレンダー」「設定」を切り替えることで個別の操作ができます。

タスクを追加するには画面右下の＋をクリックまたはタップしていただくと可能です。

### ホーム
追加されたタスクが一覧で表示され、管理できます。期限が近いものは上に表示され、オレンジ色でハイライトされます。特に近いものあるいは過ぎてしまったものは赤色でハイライトされます。その下には今まで追加してきたタスクがカテゴリーごとに分類されて表示されます。

タスクの内容が表示されているコンテナをクリックまたはタップすると詳細がご覧いただけます。また、そこでタスクの編集とURL経由での共有が行えます。

logcalの各種設定が行えます。テーマの変更や、データの管理、通知許可など。


# 特別な機能
既存のアプリには存在しないであろう特別な機能を搭載しているので紹介します。

<sub>※以下の機能は予期せず変更あるいは削除される場合がありますのでご了承ください。</sub>

### ファイル添付
logcalはタスクにファイルを添付することができます。画像からプレゼンテーションファイルまでなんでも可能です。

### カテゴリー
既存のものは運営が用意したものしか使えないという問題がありました。そこでlogcalは自分で管理・追加できるシステムを構築しました。さらに、色も自由に変更可能です。

### テーマ
logcalでは気分に合わせて変更できるテーマが８つ用意されています。設定の「テーマを選択」で変えられます。

### 通知
通常の通知に加え、期限が迫ると何回も通知してきます。うるさいと感じるなら完了してください。（通知機能を利用するには設定の「通知を許可」から通知を許可してください。）

### 完了をマークと削除の確認画面
完了をマークするとき及び削除するときに、そのタスクの名前を入力しないと削除できないポップアップを用意しています。これで間違って削除してしまうことはありませんね。この機能に関しては、邪魔だと思う人もいると思うので設定からオフにすることが可能です。そのせいで間違って消えても責任は取りませんよ！
### Google連携機能
logcalは「Googleでログイン」をサポートしています。~~正式名称がわからない~~ Googleでログインすれば、そのアカウントにデータが保存されるのでどこでも予定を確認することができます。ちなみに添付したファイルも同期されます。なお、通知許可は端末ごとの設定なのでそれぞれに許可してください。
